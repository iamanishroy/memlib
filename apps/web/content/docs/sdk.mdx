## Installation

```bash
npm install memlib
```

## Configuration

```ts
import { MemLib } from "memlib";

const memlib = new MemLib({
  apiKey: "sk_...",         // Required — your API key
  namespace: "my-app",      // Required — default namespace
  entity: "user-123",       // Required — default entity
  baseUrl: "https://...",   // Optional — defaults to MemLib cloud
});
```

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `apiKey` | `string` | ✅ | API key from your project dashboard |
| `namespace` | `string` | ✅* | Default namespace (can override per call) |
| `entity` | `string` | ✅* | Default entity (can override per call) |
| `baseUrl` | `string` | — | Custom API base URL |

\* Required either in constructor or per-call options.

## Methods

### `store(options)`

Store a memory with optional LLM-powered fact extraction.

```ts
const result = await memlib.store({
  content: "I love TypeScript and prefer dark mode",
  infer: true,          // default: true — extract facts via LLM
  tags: ["preferences"],
  metadata: { source: "onboarding" },
  source: "chat",
  ttl: 86400,           // expire after 24 hours
});
```

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `content` | `string` | ✅ | The text to store |
| `namespace` | `string` | — | Override default namespace |
| `entity` | `string` | — | Override default entity |
| `infer` | `boolean` | — | Use LLM to extract facts (default: `true`) |
| `tags` | `string[]` | — | Tags for categorization |
| `metadata` | `Record` | — | Arbitrary key-value metadata |
| `source` | `string` | — | Source identifier |
| `ttl` | `number` | — | Time-to-live in seconds |

---

### `recall(options)`

Semantic search — find memories by meaning.

```ts
const memories = await memlib.recall({
  query: "What does the user like?",
  limit: 5,
  category: "preference",
  tags: ["preferences"],
  minImportance: 0.5,
});
```

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `query` | `string` | ✅ | Semantic search query |
| `namespace` | `string` | — | Override default |
| `entity` | `string` | — | Override default |
| `category` | `string` | — | Filter by category |
| `limit` | `number` | — | Max results |
| `tags` | `string[]` | — | Filter by tags |
| `minImportance` | `number` | — | Minimum importance score |

---

### `prepare(options)`

Context-aware synthesis. Reads conversation + retrieves relevant memories → returns a ready-to-use context paragraph.

```ts
const { context, memoriesUsed, tokenCount } = await memlib.prepare({
  messages: [
    { role: "user", content: "Help me plan my weekend" },
  ],
  maxCandidates: 20,
  maxTokens: 500,
});
```

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `messages` | `Message[]` | ✅ | Conversation messages |
| `namespace` | `string` | — | Override default |
| `entity` | `string` | — | Override default |
| `maxCandidates` | `number` | — | Max memories to consider |
| `maxTokens` | `number` | — | Max tokens in output |
| `category` | `string` | — | Filter by category |

---

### `list(options?)`

List memories in a namespace.

```ts
const memories = await memlib.list({ limit: 50 });
```

---

### `delete(memoryId)`

Delete a memory by ID.

```ts
await memlib.delete("memory-uuid-here");
```

---

### `batchStore(options)`

Store multiple memories at once (no LLM inference).

```ts
const result = await memlib.batchStore({
  memories: [
    { content: "Likes coffee" },
    { content: "Works remotely" },
  ],
});
```

---

### `health()`

Check API connectivity.

```ts
const status = await memlib.health();
```
